## Суть задачи в трёх абзацах

Akinotcho et al. (ICSE 2025) показали, что GUI-исследование Android-приложения покрывает лишь
~30% активити популярных приложений из Google Play (инструменты 22.4%, люди 28.1%, вместе 29.6%),
и это потолок: люди почти не обгоняют роботов. Они вручную разобрали 363 недостигнутых активити
и вывели таксономию из 10 причин недостижимости: Server dependencies, Alternate entry,
External resources, Disabled, Error handling, Device, Environment, Usage patterns, Transitive,
No caller (+ Inconclusive).

Моя курсовая перенесла эту таксономию с уровня GUI-экранов на уровень сетевых вызовов. Пайплайн:
статически извлечь все HTTP-эндпоинты из APK (JADX + BFScan) → вручную собрать реальный трафик
Burp Suite, исследуя приложение до точки насыщения → скриптом `compare.py` найти запросы, которые
есть в коде, но отсутствуют в трафике (NOT FOUND) → классифицировать их эвристиками по URL.
Результат на 5 приложениях (Yandex Music, Ivi, Dodo Pizza, TNT Premier, Paycash): **671 из 1106
статических запросов (~61%) ни разу не вызваны**, доминируют Server dependencies (31.0%) и
External resources (19.5%).

Диплом должен **убрать ручные части этого пайплайна**: автоматизировать сбор трафика (GUI-робот
вместо человека), заменить эвристики по URL анализом условий вызова в байт-коде, добавить
проверку принудительным вызовом (Frida), и проверить устойчивость к обфускации (ProGuard/R8).
Главный количественный вопрос: какая доля скрытых запросов может быть активирована и какой
минимальной техникой — это HTTP-аналог Таблицы IV из ICSE 2025.

**Что уже сделано в этом репозитории** (детали и оговорки — `CONTEXT.md` §4.7):
точное сопоставление статика↔динамика по ключу `класс->метод` через Frida (`diff.py`,
`trace.py`, `hook.js`) и статический обратный срез скрытых запросов — call-sites, стражи
вызова, источники аргументов (`slice.py`), с инструментом ground-truth-валидации
(`eval_slice.py`). Пилот на TNT Premier есть, ручная ground-truth разметка (RQ2) — ещё нет,
поэтому числа пилота пока не для цитирования в тексте ВКР без оговорок.

## Ключевые цифры, которые понадобятся постоянно

- ICSE 2025, TopGP (42 приложения Google Play): tools 22.4%, manual 28.1%, total 29.6%.
- ICSE 2025, причины (доля от 363 недостигнутых активити): Transitive 19.6%, Server 14.3%,
  Alternate entry 13.8%, External resources 12.9%, No caller 12.4%, Disabled 11%,
  Error handling 6.1%, Device 5%, Environment 2.5%, Usage patterns 0.8%, Inconclusive 17.1%.
- ICSE 2025, RQ3: 22.7% активити активируются тривиально, +24.3% при генерации данных,
  47.6% требуют разрешения обязательных стражей. Exported только 16.8%.
- Курсовая, 671 NOT FOUND: Server 31.0%, External 19.5%, No caller 9.1%, Inconclusive 7.9%,
  Error handling 6.6%, Disabled 6.4%, Alternate entry 6.3%, Usage patterns 5.7%,
  Environment 4.2%, Device 3.4%.
- Курсовая, оценка на будущее: **~40% NOT FOUND имеют одно-два простых условия вызова**.
- Стенд обеих работ: Google Pixel XL, Android 10 (API 29).
